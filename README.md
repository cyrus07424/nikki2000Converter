# 日記帳2000 CSV Converter

## 概要

このプロジェクトは、ぽてと様による日記帳フリーソフト「[日記帳2000](https://www.poteto-house.com/poteto/soft-old.html#nikki)」で作成された日記データ（`.DAY`ファイル）をデコードし、CSV形式に変換するためのPythonスクリプト群です。

## 主な機能

-   `.DAY`形式の日記ファイルをデコードします。
-   日付、天気、気分、記念日フラグ、そして日記の本文を抽出します。
-   抽出したすべてのデータを、一つのCSVファイル（`diary.csv`）に出力します。

## 使い方

1.  `DATA`ディレクトリに、日記帳2000で作成した`.DAY`ファイルを配置します。
2.  以下のコマンドを実行します。

```bash
python decode_all.py
```

3.  スクリプトの実行が完了すると、プロジェクトのルートディレクトリに`diary.csv`が生成されます。

### CSVフォーマット

出力されるCSVファイルは以下の列を含みます。

-   `date`: 日付 (YYYY-MM-DD)
-   `weather`: 天気
-   `mood`: その日の気分
-   `is_anniversary`: 記念の日であるかどうかのフラグ (True/False)
-   `entry`: 日記の本文（改行は `\n` に置換されます）

すべての列はダブルクォーテーションで囲まれています。

## ファイル構成

-   `decode_all.py`: 全ての`.DAY`ファイルをデコードし、CSVを生成するメインスクリプトです。
-   `DATA/`: 日記帳2000の日記データ（`.DAY`ファイル）を格納するディレクトリです。

## デコード仕様

-   **エンコード**: 本文およびヘッダの一部は、`0x12`とのXOR（排他的論理和）によってエンコードされています。
-   **文字コード**: Shift-JIS
-   **ファイル構造**: 各`.DAY`ファイルは、13バイトのファイルヘッダと、それに続く日ごとのエントリで構成されています。
